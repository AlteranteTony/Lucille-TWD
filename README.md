# Lucille-TWD
it's a 3d Lucille so you could slay some imaginary walkers

![image alt](https://github.com/AlteranteTony/Lucille-TWD/blob/3e8c4fd3cbc17c98119110db8dd3eda6d3709829/lucille%20picture/final%20look.png)

# what it is 
it is cad project which includes Lucille, the iconic barbed-wire-wrapped baseball bat of Negan from The Walking Dead.
Designed in Onshape as a personal CAD and 3D modeling project



# what does lucille do:
Besides from slaying imaginary walkers it has various uses :
- prop 
- display piece 
- fan collection 

# What is in the repo 
this repo includes STL files so that you could print lucille for your self , it also includes the editable files so that you can change it according to your preference.

# Tech stack
- onshape
- cura

## you may scale the model according to your preference 

# Motivation behind making of Lucille
As my first project i wanted to make something cool and memorable. (beginner btw) i always have been fond of shows that portray survival in the wild , The Walking Dead has been one of the best shows i ever watched so i wanted to always remember the first time i watched TWD . so i made it to remember how i felt it watching for the first time.

Beyond recreating a recognizable piece from the show, I wanted to challenge myself to take an idea from concept to a finished digital design. Lucille represents my curiosity, creativity, and willingness to learn through hands-on engineering projects.
